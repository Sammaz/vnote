# 随手笔记功能扩展设计文档

## 1. 产品需求概述

### 1.1 目标
在现有的随手笔记标签页中新增两个子标签页：
- **思维导图**：用户从零开始创建思维导图，功能比视觉化总结的思维导图更完善
- **无限画布**：基于 React Flow 的自由画布，支持多种节点类型和丰富的编辑功能

### 1.2 核心需求
- **思维导图功能**：完整编辑功能（节点样式、图标、链接、备注、导出）
- **无限画布功能**：完整协作功能（文本、便签、图片、Markdown、代码块、形状节点）
- **数据存储**：分别存储在独立的数据库字段（quick_notes_mindmap、quick_notes_canvas）
- **初始状态**：带引导提示的空白画布
- **布局选项**：思维导图支持多种布局（逻辑结构、组织架构、鱼骨图等）

   - 删除节点
   - 复制/粘贴节点

3. **样式编辑**
   - 节点颜色（背景色、文字色、边框色）
   - 字体大小和样式
   - 节点形状
   - 连接线样式

4. **高级功能**
   - 插入图标（内置图标库）
   - 插入链接
   - 添加备注
   - 插入图片

5. **视图控制**
   - 撤销/重做
   - 适应画布
   - 放大/缩小
   - 全屏模式

6. **导出功能**
   - 导出为 PNG
   - 导出为 SVG
   - 导出为 PDF
   - 导出为 Markdown

### 2.4 无限画布标签页

#### 2.4.1 工具栏设计
```
┌─────────────────────────────────────────────────────────────┐
│ [选择] [手型] | [文本] [便签] [图片] [Markdown] [代码]      │
│ [矩形] [圆形] [菱形] [箭头] | [连接线] [分组]               │
│ | [撤销] [重做] | [适应画布] [放大] [缩小] | [导出▼]         │
└─────────────────────────────────────────────────────────────┘
```

**工具栏功能分组：**
1. **基础工具**
   - 选择工具（默认）
   - 手型工具（平移画布）

2. **节点类型**
   - 文本节点：纯文本输入
   - 便签节点：带背景色的便签卡片
   - 图片节点：上传或粘贴图片
   - Markdown 节点：支持 Markdown 渲染
   - 代码块节点：带语法高亮的代码编辑器

3. **形状节点**
   - 矩形
   - 圆形/椭圆
   - 菱形
   - 箭头

4. **连接与组织**
   - 连接线工具（直线、曲线、折线）
   - 分组功能（框选多个节点创建组）

5. **视图控制**
   - 撤销/重做
   - 适应画布
   - 放大/缩小
   - 小地图（可选）

6. **导出功能**
   - 导出为 PNG
   - 导出为 SVG
   - 导出为 JSON（数据格式）

#### 2.4.2 节点类型详细设计

**1. 文本节点**
```
┌─────────────────┐
│ 这是文本内容     │
└─────────────────┘
```
- 双击编辑
- 支持多行文本
- 可调整字体大小和颜色

**2. 便签节点**
```
┌─────────────────┐
│ 📌 便签标题      │
├─────────────────┤
│ 便签内容...      │
│                 │
└─────────────────┘
```
- 带标题栏
- 可选背景色（黄色、蓝色、绿色、粉色等）
- 支持富文本编辑

**3. 图片节点**
```
┌─────────────────┐
│                 │
│   [图片显示]     │
│                 │
└─────────────────┘
```
- 支持拖拽上传
- 支持粘贴图片
- 可调整大小
- 可添加图片说明

**4. Markdown 节点**
```
┌─────────────────┐
│ # 标题          │
│ - 列表项        │
│ **粗体**        │
└─────────────────┘
```
- 实时预览
- 支持完整 Markdown 语法
- 可切换编辑/预览模式

**5. 代码块节点**
```
┌─────────────────┐
│ JavaScript ▼    │
├─────────────────┤
│ const x = 1;    │
│ console.log(x); │
└─────────────────┘
```
- 语法高亮
- 支持多种语言
- 行号显示
- 可复制代码

**6. 形状节点**
```
┌─────────────────┐    ╱─────────╲
│   矩形文本       │   │  菱形文本  │
└─────────────────┘    ╲─────────╱

    ┌─────┐
   │ 圆形 │
    └─────┘
```
- 可填充颜色
- 可设置边框样式
- 可添加文本标签

#### 2.4.4 连接线设计
- **样式选项**：直线、曲线、折线、箭头

### 2.5 交互设计

#### 2.5.1 子标签页切换
- 点击子标签页切换内容
- 切换时自动保存当前标签页的数据
- 每个标签页的数据独立存储

#### 2.5.2 快捷键设计

**思维导图快捷键：**
- `Tab`：添加子节点
- `Enter`：添加兄弟节点
- `Delete`：删除节点
- `Ctrl+Z`：撤销
- `Ctrl+Y`：重做
- `Ctrl+C/V`：复制/粘贴
- `F2`：编辑节点
- `Space`：展开/折叠节点

**无限画布快捷键：**
- `V`：选择工具
- `H`：手型工具
- `T`：文本节点
- `N`：便签节点
- `L`：连接线工具
- `Ctrl+Z`：撤销
- `Ctrl+Y`：重做
- `Ctrl+A`：全选
- `Delete`：删除选中节点
- `Ctrl+G`：创建分组
- `Ctrl+Shift+G`：取消分组

#### 2.5.3 自动保存
- 编辑后 1 秒自动保存到数据库
- 保存时显示保存状态提示（可选）
- 切换标签页时立即保存

### 3.4 API 设计

#### 3.4.1 前端 API

**保存思维导图：**
```typescript
await invoke("update_note_content", {
  noteId: number,
  tabType: "quick_notes_mindmap",
  content: string // JSON 字符串
});
```

**保存无限画布：**
```typescript
await invoke("update_note_content", {
  noteId: number,
  tabType: "quick_notes_canvas",
  content: string // JSON 字符串
});
```

**导出思维导图为图片：**
```typescript
const dataUrl = mindMapInstance.export('png', true, '我的思维导图');
// 使用 Tauri 的文件保存对话框
const filePath = await save({
  defaultPath: '思维导图.png',
  filters: [{ name: 'PNG', extensions: ['png'] }]
});
```

#### 3.4.2 后端 API（Rust）

需要在 `src-tauri/src/commands.rs` 中扩展 `update_note_content` 命令，支持新的 `tabType`：

```rust
match tab_type.as_str() {

            .await?;

    "quick_notes_mindmap" => {
        sqlx::query("UPDATE notes SET quick_notes_mindmap = ? WHERE id = ?")

        sqlx::query("UPDATE notes SET quick_notes_canvas = ? WHERE id = ?")
            .bind(&content)
            .bind(note_id)
            .execute(&state.db)
            .await?;
    }
    // ... 其他 tab_type
}
```

## 5. 注意事项

### 5.1 性能考虑
- 思维导图节点数量超过 100 时考虑虚拟化
- 无限画布节点数量超过 50 时考虑性能优化
- 图片节点使用懒加载
- 自动保存使用防抖（1 秒）

### 5.2 兼容性
- 确保与现有的富文本编辑器不冲突
- 数据迁移时保持向后兼容
- 主题切换时同步更新思维导图和画布

### 5.3 用户体验
- 首次使用时显示引导提示
- 操作失败时给出明确的错误提示
- 保存状态实时反馈
- 支持键盘快捷键提高效率

### 5.4 安全性
- 图片上传时验证文件类型和大小
- 防止 XSS 攻击（特别是 Markdown 和代码块节点）
- 数据保存时进行 JSON 验证
